# Pulmoaid Mobile Application

Mobile application developed using HTML, CSS, JavaScript, Vite and Capacitor.

Features:
- BLE communication with ESP32-S3.
- Real-time pressure monitoring.
- Pressure-time integration.
- Maximum and minimum pressure tracking.
- Assessment and Training modes.
- CSV data generation and export.
